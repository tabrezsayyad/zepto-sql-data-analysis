# Zepto SQL Data Analysis

## Project Overview
This project analyzes Zepto product data using PostgreSQL.

## Tools Used
- PostgreSQL
- SQL
- pgAdmin

## Analysis Performed
- Data exploration
- Data cleaning
- Discount analysis
- Out-of-stock product analysis
- Category-wise revenue analysis
- Inventory value analysis
- Price per gram analysis
- Weight categorization

## Key SQL Concepts
- SELECT
- WHERE
- GROUP BY
- HAVING
- ORDER BY
- CASE
- Aggregate Functions
- ROUND
- DISTINCT
